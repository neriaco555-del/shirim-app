# שירים — אפליקציית מוזיקה

**גרסה נוכחית: 1.6.3**

אפליקציה בעברית לחיפוש והאזנה לשירים מיוטיוב, עם פלייליסטים אישיים, הורדות להאזנה לא מקוונת, חיתוך שירים ושמירה למכשיר, חיפוש לפי כיוון (חילוני / דתי / חרדי) או לפי זמרים, וסטטיסטיקות שימוש.

## הורדה והתקנה

הקישור תמיד מוריד את הגרסה העדכנית:

https://github.com/neriaco555-del/shirim-app/releases/latest/download/shirim.apk

לאחר ההתקנה הראשונה, האפליקציה בודקת עדכונים אוטומטית ומציעה לעדכן. אין צורך להוריד APK חדש בכל פעם.

## מה כלול

- חיפוש שירים, אמנים ואלבומים מיוטיוב
- נגן עם תור, ערבוב וחזרה
- פלייליסטים אישיים (יצירה, הוספת שירים, שינוי שם ומחיקה)
- חיפוש לפי כיוון מוזיקלי ולפי זמרים
- הורדות להאזנה ללא אינטרנט, כולל שמירה ב"הורדות" של הטלפון
- חיתוך שיר ובחירת קטע לשמירה
- עדכונים אוטומטיים והתראות מערכת על עדכונים
- סטטיסטיקות שימוש אנונימיות: מחוברים עכשיו, פעילים לאחרונה, ופירוט הורדות לפי גרסה

## עדכונים

הגרסה העדכנית נמצאת תמיד בקישור הקבוע למעלה. עדכונים מוצגים בתוך האפליקציה.

התוכן מוזרם מיוטיוב באמצעות NewPipeExtractor (GPLv3). ההורדות מיועדות לשימוש אישי בלבד.
